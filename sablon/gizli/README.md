# Gizli

Şifre, API anahtarı, token, kart ve banka bilgisi yalnız bu klasöre yazılır.

- Bu dosya dışında klasördeki hiçbir şey git'e girmez (`.gitignore`). GitHub'a gitmez, yalnız bu
  bilgisayarda durur. Öbür bilgisayarda da lazımsa kendiniz taşıyın.
- Kartlarda değerin kendisi değil yeri yazılır: "anahtar: `gizli/<dosya>.md`".
- Yine de en güvenli yer bir şifre yöneticisidir. Buraya yalnız Claude'un işte kullanması gerekenleri koyun.
